# 02. 屬性相剋與多重乘區

## 1. 核心定義
全系列共有 **18 種屬性**，招式屬性與防守方寶可夢屬性的相剋關係，會直接決定最終傷害的**「屬性倍率（Type Effectiveness）」**，是對戰中影響傷害幅度最劇烈的乘區（從 $0\times$ 到 $4\times$）。

## 2. 精確公式與倍率表

### 單一屬性相剋倍率
- **效果絕佳（Super Effective）**：**$2\times$**
- **一般效果（Normal）**：**$1\times$**
- **效果不好（Not Very Effective）**：**$0.5\times$**
- **沒有效果（Immune）**：**$0\times$**（完全不受傷害，且通常不觸發招式附加效果）

### 雙屬性防守方的疊加計算規則
當防守方擁有兩種屬性（屬性 A 與屬性 B）時，最終屬性倍率為兩者相乘：
$$\text{Type Multiplier} = \text{Multiplier}_A \times \text{Multiplier}_B$$

| 屬性 A 倍率 | 屬性 B 倍率 | 最終倍率 | 對戰俗稱與戰術意義 |
| :--- | :--- | :--- | :--- |
| $2\times$ | $2\times$ | **$4\times$** | **四倍弱點**：極易被一擊秒殺（如冰屬性招式打烈咬陸鯊）。 |
| $2\times$ | $1\times$ | **$2\times$** | **兩倍弱點**：常見的進攻突破口。 |
| $2\times$ | $0.5\times$ | **$1\times$** | **等倍抵銷**：雙屬性互相彌補了原本的弱點。 |
| $0.5\times$ | $0.5\times$ | **$0.25\times$** | **四倍抗性**：傷害極低，適合切換上場承受攻擊。 |
| 任意倍率 | $0\times$ | **$0\times$** | **屬性無效**：只要其中一個屬性無效，總傷害直接歸零。 |

### 七大經典「屬性無效（$0\times$）」對照
1. **一般系**招式 $\rightarrow$ 打**幽靈系**無效（反之幽靈系打一般系亦無效）。
2. **格鬥系**招式 $\rightarrow$ 打**幽靈系**無效。
3. **地面系**招式 $\rightarrow$ 打**飛行系**無效。
4. **電系**招式 $\rightarrow$ 打**地面系**無效。
5. **超能力系**招式 $\rightarrow$ 打**惡系**無效。
6. **毒系**招式 $\rightarrow$ 打**鋼系**無效。
7. **龍系**招式 $\rightarrow$ 打**妖精系**無效。

## 3. 實戰計算舉例
- **情境**：對手派出「巨沼怪（水／地面屬性）」。
- **攻擊 A（草屬性招式《能源球》）**：草剋水（$2\times$）且草剋地面（$2\times$） $\rightarrow$ $2 \times 2 =$ **$4\times$ 傷害**。
- **攻擊 B（電屬性招式《十萬伏特》）**：電剋水（$2\times$），但地面對電無效（$0\times$） $\rightarrow$ $2 \times 0 =$ **$0\times$ 傷害（完全無效）**。

## 4. 新手常見誤區
- **誤區 1（以為雙屬性無效會變成 $0.5\times$）**：只要防守方有任一屬性對該招式無效，不論另一屬性是否被剋制，結果一律是 **$0\times$**。
- **誤區 2（太晶化後仍保留原本雙屬性抗性）**：寶可夢太晶化後，**防禦屬性會完全變成單一的「太晶屬性」**，原本的雙屬性弱點與抗性都會被覆蓋。
