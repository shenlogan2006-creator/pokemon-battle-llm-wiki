# 03. 能力值系統與培養機制

## 1. 核心定義
每隻寶可夢擁有 **HP、攻擊、防禦、特攻、特防、速度** 六項能力值。前五項決定「打人有多痛」與「有多耐打」，而**速度（Speed）則直接決定雙方誰先出手**。

## 2. 精確公式與倍率表

### 六大能力值實數計算公式
1. **HP 計算公式**：
   $$\text{HP} = \left\lfloor \frac{(2 \times \text{種族值} + \text{個體值} + \lfloor \text{努力值}/4 \rfloor) \times \text{等級}}{100} \right\rfloor + \text{等級} + 10$$
2. **其他五項（攻擊、防禦、特攻、特防、速度）計算公式**：
   $$\text{能力值} = \left\lfloor \left( \left\lfloor \frac{(2 \times \text{種族值} + \text{個體值} + \lfloor \text{努力值}/4 \rfloor) \times \text{等級}}{100} \right\rfloor + 5 \right) \times \text{性格修正} \right\rfloor$$

### 決定能力高低的四大培育要素
| 要素名稱 | 數值範圍 | 特性與對戰影響 |
| :--- | :--- | :--- |
| **種族值（Base Stats）** | 因物種而異 | 決定該寶可夢的天生定位（例如快龍物攻 134、胡地特攻 135）。 |
| **個體值（IV）** | **$0 \sim 31$** | 先天資質，正式對戰通常透過王冠特訓將關鍵能力升至滿值 $31$（俗稱 $V$）。 |
| **努力值（EV）** | 單項 **$0 \sim 252$**<br>總和上限 **$510$** | 後天分配點數。**在 Lv.50 下，最初 4 點 $+1$ 能力，之後每 8 點 $+1$ 能力**（滿項 252 共增加 32 點能力）。 |
| **性格（Nature）** | **$1.1\times$ / $0.9\times$** | 挑選「增加優勢項、降低無用項」的性格（如物攻手選固執 $+攻 -特攻$）。 |

### 速度線與出手順序判定
- 一般情況下，**有效速度實數值較高的一方先行動**。
- 若雙方速度實數值完全相同（同速），系統以 **$50\%$ 機率**隨機決定先後。
- 若場上開啟**《戲法空間（Trick Room）》**（持續 5 回合），則**速度較慢的一方先行動**。

## 3. 實戰計算舉例
- **情境**：Lv.50 烈咬陸鯊（速度種族值 $102$），個體值 $31$、努力值練滿 $252$。
- **性格「爽朗（速度 $1.1\times$）」**：速度實數值為 **$169$**。
- **性格「固執（速度 $1.0\times$）」**：速度實數值為 **$154$**。
- **對戰差距**：僅僅性格的 $1.1\times$ 修正，就讓爽朗烈咬陸鯊在對決時必然比固執烈咬陸鯊先出手。

## 4. 新手常見誤區
- **誤區 1（努力值把 510 點平均分給六項）**：因總上限只有 $510$，新手最穩健的練法是**「極限二項（252 / 252 / 4）」**（例如速度 252 ＋ 物攻 252 ＋ HP 4），把優勢發揮到極致。
- **誤區 2（在 Lv.50 練出 248 或 250 點努力值）**：在 Lv.50 規則中，$244$ 點增加 $31$ 能力值，$252$ 點增加 $32$ 能力值，中間的 $248$ 與 $250$ 並不會多加能力，配置時需注意 $4 + 8n$ 的階梯規律。
