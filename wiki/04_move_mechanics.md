# 04. 招式分類、威力與優先度

## 1. 核心定義
招式是寶可夢在回合中執行的指令，依據**「傷害計算方式」**分為三大類，並透過**「優先度（Priority）」**與**「接觸判定」**影響出手順序與特性觸發。

## 2. 精確公式與倍率表

### 招式三大分類與攻防對應
| 招式分類 | 進攻方使用能力 | 防守方承受能力 | 代表招式舉例 |
| :--- | :--- | :--- | :--- |
| **物理招式（Physical）** | **攻擊（Atk）** | **防禦（Def）** | 《近身戰》、《地震》、《閃焰衝鋒》 |
| **特殊招式（Special）** | **特攻（Sp. Atk）** | **特防（Sp. Def）** | 《十萬伏特》、《暗影球》、《流星群》 |
| **變化招式（Status）** | 無直接傷害 | 無直接傷害 | 《劍舞》、《電磁波》、《守住》 |

*(註：極少數特殊招式有例外規則，例如《精神衝擊》雖為特殊招式，但計算對手的「防禦」而非特防；《撲擊》雖為物理招式，但使用自身的「防禦」而非攻擊。)*

### 優先度（Priority）機制
優先度等級高於速度值：**優先度高的招式永遠比優先度低的招式先使出**，即使在《戲法空間》內亦同；只有當雙方招式「優先度相同」時，才比較速度值。

| 優先度 | 常見招式與效果說明 |
| :--- | :--- |
| **$+4$** | 《守住（Protect）》、《看穿》（阻擋當回合對手攻擊，連續使用成功率下降） |
| **$+3$** | 《擊掌奇襲（Fake Out）》（僅限出場第一回合使用，必定使目標畏縮） |
| **$+2$** | 《神速（Extreme Speed）》（高威力一般系先制攻擊） |
| **$+1$** | 《電光一閃》、《子彈拳》、《水流噴射》、《突襲》（常見收尾先制技） |
| **$0$** | 絕大多數常規攻擊與變化招式 |
| **$-6$** | 《吹飛》、《吼叫》、《龍尾》（強制將對手換下場的後制招式） |
| **$-7$** | 《戲法空間（Trick Room）》（扭轉場上速度順序 5 回合） |

## 3. 實戰計算舉例
- **情境**：我方「巨鉗螳螂」（速度僅 $85$，但擁有特性《技術高手》，使威力 $\le 60$ 的招式威力變為 $1.5\times$）對上速度高達 $180$ 的殘血對手。
- **行動**：巨鉗螳螂使用優先度 **$+1$** 的《子彈拳》（基礎威力 $40$，經特性變為 $60$，加上鋼屬性 STAB $1.5\times$ 達 $90$ 等效威力）。
- **結果**：因優先度 $+1 > 0$，巨鉗螳螂無視速度差距搶先出手完成擊殺。

## 4. 新手常見誤區
- **誤區 1（讓高物攻寶可夢學高威力特殊招式）**：例如給「攻擊 134、特攻 95」的快龍配《十萬伏特》，雖然屬性克制水系，但因套用較低的特攻值，傷害遠不如使用自身的物理招式。
- **誤區 2（以為「物理招式＝接觸類招式」）**：兩者並不等同！例如《地震》、《岩崩》是物理招式但**不接觸對手**（不會觸發對手的《靜電》或《凸凸頭盔》）；《打草結》、《吸取之吻》則是特殊招式但**屬於接觸類招式**。
