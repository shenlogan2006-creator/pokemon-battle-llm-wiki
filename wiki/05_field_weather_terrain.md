# 05. 場地因素：天氣與場地（Terrain）

## 1. 核心定義
對戰中的環境狀態分為**「天氣（Weather）」**與**「場地（Terrain）」**兩大獨立系統（兩者可同時存在），預設持續 **5 回合**（攜帶對應岩石或大地膜道具可延長至 **8 回合**），直接提供大幅度的屬性增傷、減傷或防禦加成。

## 2. 精確公式與倍率表

### 四大天氣（Weather）對照表（第九世代規則）
| 天氣名稱 | 觸發特性 / 招式 | 傷害與能力修正 | 額外戰術效果 |
| :--- | :--- | :--- | :--- |
| **大晴天（Sun）** | 特性《日照》 / 招式《大晴天》 | **火屬性招式 $1.5\times$**<br>**水屬性招式 $0.5\times$** | 《日光束》無需蓄力；水系招式《水蒸氣》在晴天下反獲 $1.5\times$ 增傷。 |
| **下雨（Rain）** | 特性《降雨》 / 招式《求雨》 | **水屬性招式 $1.5\times$**<br>**火屬性招式 $0.5\times$** | 《打雷》、《暴風》變為必中（無視命中率）。 |
| **沙暴（Sandstorm）** | 特性《揚沙》 / 招式《沙暴》 | **岩石屬性寶可夢特防 $1.5\times$** | 非岩石、地面、鋼屬性寶可夢，每回合結束損失 $1/16$ 最大 HP。 |
| **下雪（Snow）** | 特性《降雪》 / 招式《雪景》 | **冰屬性寶可夢防禦 $1.5\times$** | **第九世代改動：回合結束不再扣血**；《暴風雪》變為必中。 |

### 四大場地（Terrain）對照表（僅對「地面上的寶可夢」生效）
> **地面判定規則**：飛行屬性、特性《飄浮》或攜帶《氣球》的寶可夢處於浮空狀態，**不會受到任何場地效果影響**。

| 場地名稱 | 屬性傷害修正（第 8～9 世代） | 附加保護與回復效果 |
| :--- | :--- | :--- |
| **電氣場地** | 地面寶可夢使出**電屬性招式 $1.3\times$** | 地面上的寶可夢**不會陷入睡眠狀態**。 |
| **青草場地** | 地面寶可夢使出**草屬性招式 $1.3\times$** | 地面寶可夢每回合結束回復 $1/16$ HP；《地震》、《重踏》傷害減半（$0.5\times$）。 |
| **精神場地** | 地面寶可夢使出**超能力屬性招式 $1.3\times$** | **完全封鎖對手對地面目標使出的先制招式（優先度 $> 0$）**。 |
| **薄霧場地** | 地面寶可夢受到**龍屬性招式傷害減半（$0.5\times$）** | 地面上的寶可夢**不會陷入異常狀態與混亂**（不會增加妖精招式威力）。 |

## 3. 實戰計算舉例
- **情境**：雨天隊核心「大嘴鷗（特性《降雨》）」上場開啟雨天，隊友「巨沼怪（水／地面）」使出水屬性物理招式《水流裂破》（威力 $85$）。
- **乘區疊加**：基礎威力 $85 \times \text{STAB } 1.5\times \times \text{雨天 } 1.5\times = \mathbf{191.25}$ 等效威力（傷害提升為原本的 $2.25$ 倍）。

## 4. 新手常見誤區
- **誤區 1（以為下雪還會像以前冰雹一樣每回合扣血）**：第九世代已將冰雹改為下雪，**不再有扣血效果**，改為直接強化冰屬性的物理防禦 $1.5\times$。
- **誤區 2（在精神場地上對飛行系使用先制招式失敗）**：精神場地只保護「處於地面上」的寶可夢，如果目標是飛行屬性（如快龍），你依然可以用《神速》或《擊掌奇襲》打中它。
